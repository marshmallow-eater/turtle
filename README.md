# Turtle Beach Guardian

An isometric Phaser arcade game where you protect baby turtles as they rush to the ocean.

## 🚀 Play Now
You can play the game directly on GitHub Pages:
**[https://marshmallow-eater.github.io/turtle/](https://marshmallow-eater.github.io/turtle/)**

## 🛠️ Development

This project is built using:
- **Phaser 4 / TypeScript**
- **Vite**
- **Bun** (for package management and builds)

### Scripts

- Run development server:
  ```bash
  bun run dev
  ```
- Build for production:
  ```bash
  bun run build
  ```
- Preview production build:
  ```bash
  bun run preview
  ```

## 📦 Deployment

Deployments to GitHub Pages are automated via GitHub Actions on every push to the `main` branch.
